全体の地図

試験の話は、ほとんどが「あなたのアプリが Claude を1回呼ぶ」流れのどこかに乗っています。

  1. アプリ（クライアント）が、HTTP でリクエストを作る（宛先・ヘッダー・JSON の本文）
  2. Claude API が受け取り、制限（レート制限・支出上限）を確かめる
  3. モデルがトークンを読み、必要なら考え（思考）、必要ならツールを頼む
  4. レスポンスが返る（中身のブロック・止まった理由・使ったトークン数）
  5. アプリが結果を使う。ツールを頼まれていたら実行して、また 1 へ

章はこの流れの順に並んでいます。問題文で分からない言葉が出たら、「この流れのどこの話か」を先に考えると、選択肢が絞りやすくなります。
